# Paquete de Dominio de Huella Forense

Contiene los módulos principales de la plataforma:
- `core/`: Gestor de casos modulares.
- `models/`: Esquemas tipados Pydantic v2.
- `knowledge/`: Base de datos SQLite WAL y RAG de evidencia judicial.
- `scenarios/`: Agentes conversacionales y máquina de estados de audiencias/reuniones.
- `evaluation/`: Rúbricas y motor de valoración y feedback del estudiante.
- `estimation/`: Estimador técnico de esfuerzo de I+D/IA.
- `web/`: API REST FastAPI.
- `cli/`: Simulador interactivo en terminal con Rich.
